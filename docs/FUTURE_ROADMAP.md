# 未來功能規劃與待辦清單

更新日期：2026-08-01

## 一、最高優先：各科學習系統

- [x] 建立並發布獨立的「各科學習系統」入口網站。
- [x] 在聯絡簿正式部署設定 `VITE_LEARNING_SYSTEM_URL`，接上各科學習系統入口。
- [ ] 驗證從聯絡簿前往英文單字系統時，可沿用同一組帳號及登入狀態。
- [x] 建立學習系統連結資料：科目、名稱、網址、排序、每週次數及啟用狀態。
- [x] 建立每日專注任務：每科每週隨機 1～3 次、每天最多 4 項、一次突出一項任務。
- [x] 建立週末規則：平日未完成時隨機保留約 70％，全部完成時不新增任務。
- [x] 建立英語分組題數：A 組每項 20 題、B 組每項 10 題；一般目標 80 分、口說目標 70 分。
- [ ] 建立管理員新增、編輯、排序、隱藏及恢復學習系統連結的介面。
- [x] 英文 A 組字母拼拼樂加入 0～4 個干擾字母。
- [x] 英文 A 組將情境填空改為中文提示與完整句子重組，並完成第二冊第六課第一批教師例句庫。
- [x] 英文 A 組口說完整句子；B 組維持單字為主並混合少量簡單句。
- [x] 英文遊戲完成後回傳專注任務分數。
- [ ] 英文專注任務未達標時，只重練該回合的錯題。
- [ ] 逐步加入各科線上桌遊、學習重點、心智圖、學科漫畫及其他互動教材。
- [ ] 學習遊戲可設定「共同、數學 A、數學 B、英語 A、英語 B」對象，學生只看到共同內容及符合自己分組的內容。

英語單字系統與聯絡簿維持共用 Supabase Auth，不在網址中傳遞密碼或私人資料。

## 三、個人成績後續擴充

- [x] 分析完全在站內依規則產生，不把學生成績傳送至外部生成式 AI。
- [ ] 加入各科歷次折線圖。
- [ ] 加入段考與模擬考交叉比較。
