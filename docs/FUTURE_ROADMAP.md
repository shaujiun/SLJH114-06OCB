# 未來功能規劃與待辦清單

更新日期：2026-07-30

## 一、最高優先：各科學習系統

- [ ] 在聯絡簿正式部署設定 `VITE_LEARNING_SYSTEM_URL`，接上已建立的科目選擇首頁。
- [ ] 驗證從聯絡簿前往英文單字系統時，可沿用同一組帳號及登入狀態。
- [ ] 建立學習系統連結資料：科目、名稱、圖示、網址、教材類型、排序及啟用狀態。
- [ ] 建立管理員新增、編輯、排序、隱藏及恢復學習系統連結的介面。
- [ ] 逐步加入各科線上桌遊、學習重點、心智圖、學科漫畫及其他互動教材。
- [ ] 學習遊戲可設定「共同、數學 A、數學 B、英語 A、英語 B」對象，學生只看到共同內容及符合自己分組的內容。

英語單字系統與聯絡簿維持共用 Supabase Auth，不在網址中傳遞密碼或私人資料。

## 二、校務行事曆匯入

- [x] Excel `.xlsx` 行事曆可預覽、篩選八年級適用活動及匯入。
- [ ] 學校公告正式行事曆 PDF 後，再以實際檔案建立並測試 PDF 擷取、預覽及人工確認流程。

## 三、個人成績後續擴充

- [x] 單次成績、七科雷達圖、歷次表格、各科平均及站內 3～5 點學習分析。
- [x] 分析完全在站內依規則產生，不把學生成績傳送至外部生成式 AI。
- [ ] 加入各科歷次折線圖。
- [ ] 加入段考與模擬考交叉比較。
- [ ] 加入各科、班排及校排的長期趨勢與進退步幅度。
- [ ] 規劃任課老師只查看或管理本科成績的權限、介面及 RLS。

學生端加註：「若需更詳細的分析，可自行使用生成式 AI 協助分析。」使用外部服務時不得輸入姓名、學號或其他可識別個人身分的資料。

## 四、學習資源後續擴充

- [x] 文章、Facebook 影片、YouTube 影片及 JPG 封面已由管理員完成實際測試。
- [ ] 視實際使用需求測試 Instagram 與 Vimeo 公開影片。
- [ ] 加入閱讀或觀看紀錄。
- [ ] 加入完成狀態、學生收藏及指定期限。
- [ ] 加入指定學生、共同或分組對象。
- [ ] 學習資源中的遊戲連結可依數學及英語分組顯示。

## 五、開學後驗收

- [ ] 使用未核准教師、已核准教師、多科教師、各組小老師、作業長及一般學生帳號完成角色權限驗收。
- [ ] 學生開始使用後，同步驗收手機版、公告已讀、作業、行事曆、成績與學習資源。
- [ ] 各科學習系統入口與內容完成後，驗證跨系統共用登入及學生分組內容。

## 六、已確認不列入待辦

- 榮譽榜維持本班榮譽榜；校級、全國性比賽仍以本班學生榮譽呈現，不建立全校榮譽榜。
- 不串接外部生成式 AI，由站內規則產生個人學習分析。
- 維持目前單一班級使用，不製作多班級切換介面。
